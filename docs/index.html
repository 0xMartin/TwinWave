Key Features

Compact Design

Plugs directly into Flipper Zero's GPIO header. Designed for permanent attachment — compactness was the key motivation behind development.

Dual Radio System

Wi-Fi 2.4 GHz (ESP32-PICO-V3-02) and Sub-GHz 433 MHz (TI CC1101) in one module.

Replaceable Antennas

2× SMA female connectors let you swap antennas for optimal performance in any scenario.

Marauder Firmware

WiFi analysis, traffic monitoring and wireless penetration testing with Marauder firmware.

Independent Power Control

Micro switches for the Wi-Fi and Sub-GHz radios. Save battery by disabling unused modules.

Community Open Hardware

Transparent design with complete schematics and PCB files. Free to build, study and customize for personal use.

Flash instructions

Firmware Upload

To upload or update the ESP32 Marauder firmware, connect a USB-TTL (UART) adapter to the GPIO pin header on the bottom side of the TwinWave PCB.

UART Connection

Connect a USB-TTL adapter (CP2102, CH340, FT232) to the 10-pin GPIO header on the bottom side of the PCB.

Pin 1 (3V3)→VCC (3.3V only!)
Pin 3 (GND)→GND
Pin 5 (RX)→TX (adapter)
Pin 6 (TX)→RX (adapter)

Hold BOOT, press RESET, then release both to enter flash mode.

Web Flasher — recommended

Flash firmware directly from your browser, no installation required.

  1. Connect USB-TTL adapter to TwinWave
  2. Put ESP32 into boot mode (hold BOOT, press RESET, release both)
  3. Open the Web Flasher and follow the wizard
Open Web Flasher

For manual flashing (esptool, PlatformIO), see firmware/README.md.

Always use a 3.3V power supply. Using 5V will permanently damage the ESP32 chip.
